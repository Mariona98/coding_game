LEVEL SCRIPT REFERENCE
======================

Coordinate system: (x,y), with (0,0) at the upper-left. x increases to the
right; y increases downward. Every level has a 12-column by 12-row matrix.
Commands record actions while the Python script runs; the game applies those
actions afterward in order.


LEVEL 1 (ID 1)
==============

Matrix size: 12 x 12

Objects:
  hero    (3,5)
  DECOY   (5,4)  [ENEMY]
  button  (5,3)  [BUTTON]
  door    (8,5)  [DOOR]

Goal:
  Identify the button by its ID, step on it to open the door, then reach the
  door. Do not step on the DECOY; entering an enemy tile ends the run.

Commands:
  from game_api import hero

  hero.moveRight() / moveLeft() / moveUp() / moveDown()
    Queue one move for the hero. Each call moves one tile; up decreases y,
    down increases y. The game prevents leaving the map or entering blocked
    tiles. The closed door cannot be entered.

  hero.getObjectId("RIGHT"|"LEFT"|"UP"|"DOWN")
    Return the ID of an object in that neighboring tile, or None if the
    initial level snapshot has no object there. This is a lookup, not a live
    game query.

  hero.attack()
    Queue a melee attack. It defeats one enemy on a tile directly above,
    below, left, or right of the hero. It does not attack diagonally.

Example: move to (4,3), check for the button to the right, and only step onto
it if its ID is "button". Then continue to the door:

  from game_api import hero
  hero.moveUp()
  hero.moveRight()
  hero.moveUp()
  if hero.getObjectId("RIGHT") == "button":
      hero.moveRight()
      hero.moveRight()
      hero.moveRight()
      hero.moveDown()
      hero.moveRight()
      hero.moveDown()


LEVEL 2 (ID 11)
===============

Matrix size: 12 x 12

Objects:
  hero       (1,9)   [HERO]
  RED puzzle (6,3)   [PUZZLE]
  RED puzzle (7,3)   [PUZZLE]
  RED puzzle (6,4)   [PUZZLE]
  RED puzzle (7,4)   [PUZZLE]
  RED puzzle (6,6)   [PUZZLE]
  RED puzzle (7,6)   [PUZZLE]
  RED puzzle (6,7)   [PUZZLE]
  RED puzzle (7,7)   [PUZZLE]
  RED puzzle (6,8)   [PUZZLE]
  RED puzzle (5,9)   [PUZZLE]
  RED item   (3,5)   [ITEM / paint]

Goal:
  Activate all ten RED puzzle tiles. Pick up RED paint on the item's tile,
  then drop it while standing on a RED puzzle tile. Repeat for each puzzle.
  You can pick up to 10 "paints" at the time.

Commands:
  from game_api import hero, inventory

  hero.moveRight() / moveLeft() / moveUp() / moveDown()
    Queue one hero move by one tile in that direction.

  inventory.append()
    Queue ADD. The game picks up the item at the hero's current tile.

  inventory.remove()
    Queue DROP. The game removes the first carried item and activates a
    puzzle under the hero if the dropped item's ID matches the puzzle ID.

  hero.getObjectId("RIGHT"|"LEFT"|"UP"|"DOWN")
    Return the adjacent object's ID from the initial level snapshot, or None.

  hero.attack()
    Queue a melee attack on one orthogonally adjacent enemy. This level has
    no enemies, so it is not needed for the goal.


LEVEL 3 (ID 21)
===============

Matrix size: 12 x 12

Objects:
  hero           (3,2)   [HERO]
  function-totem (3,3)   [TOTEM]
  enemy-1        (7,2)   [ENEMY]
  enemy-2        (8,4)   [ENEMY]
  enemy-3        (11,10) [ENEMY]
  enemy-4        (5,11)  [ENEMY]
  enemy-5        (11,5)  [ENEMY]
  enemy-6        (2,7)   [ENEMY]

Goal:
  Defeat all six enemies with the totem. The hero starts adjacent to the
  totem and should stay on its safe tile. The totem can cross lava, but must
  stay inside the 12 x 12 matrix. Attacks work only against an enemy directly
  above, below, left, or right of the totem.

Commands:
  from game_api import hero, totem

  hero.command(function_name)
    Run a function as a totem-program block. The hero must be next to the
    totem when this call is executed.

  totem.moveRight() / moveLeft() / moveUp() / moveDown()
    Queue a one-tile totem move. These commands only work inside the function
    passed to hero.command(). The totem ignores tile walkability, but cannot
    leave the map.

  totem.attack()
    Queue an attack by the totem. It only works inside hero.command() and
    defeats one orthogonally adjacent enemy.


COMMAND EXECUTION NOTES
=======================

Movement and action methods queue commands; they do not return whether the
game accepted an action. Python runs first and the game applies the complete
command list afterward. getObjectId reads the initial object snapshot, so it
does not report objects that move or enemies removed later in that run.
